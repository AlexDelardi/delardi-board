- Subagents never touch production. Production changes are made only by the controller in Task 6, each after Alex's explicit yes.

- SQL tests: one file per concern under `db/tests/`, wrapped in `begin; … rollback;`, ending with `select '<name> ok' as result;`. They run on the local DB only.
